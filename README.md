# Ajay Kumar Varikuppala — Portfolio

A responsive, single-page portfolio for showcasing Ajay's work across Python, machine learning, NLP, and data projects.

## Files

- `index.html` — semantic page content and social metadata.
- `styles.css` — responsive visual system and layouts.
- `script.js` — mobile navigation, current year, and gentle scroll reveals.
- `favicon.svg` — monogram favicon.

## Publish with GitHub Pages

This site is intended for the user-site repository `ajaykumarvarikuppala.github.io`. Keep these files at the repository root and select **Settings → Pages → Deploy from a branch → main / (root)**. GitHub Pages will publish it at `https://ajaykumarvarikuppala.github.io/`.

## Personal details

The page intentionally uses public profile links only. Add a personal email address or phone number only if you want that information published on the open web.
