# Ajay Kumar Varikuppala — Portfolio

A responsive, single-page portfolio for showcasing Ajay's work across Python, machine learning, NLP, and data projects. Includes two lightweight, muted looping project visualizations and an accessible preview dialog.

## Files

- `index.html` — semantic page content and social metadata.
- `styles.css` — responsive visual system, motion, and layouts.
- `script.js` — mobile navigation, project preview dialog, visible-section reveals, and current year.
- `assets/` — compressed project preview videos and posters. Both videos are explanatory visualizations, not recordings of the original applications.
- `favicon.svg` — monogram favicon.

## Publish with GitHub Pages

This site is intended for the user-site repository `ajaykumarvarikuppala.github.io`. Keep these files at the repository root and select **Settings → Pages → Deploy from a branch → main / (root)**. GitHub Pages will publish it at `https://ajaykumarvarikuppala.github.io/`.
